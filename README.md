## 文件

- [`data/world.json`](data/world.json)：世界元数据与原压缩包校验值。
- [`data/dungeon_locations.csv`](data/dungeon_locations.csv)：所有副本入口坐标，含状态及与祭坛的距离。
- [`data/hildir_locations.csv`](data/hildir_locations.csv)：希尔迪尔任务的洞穴、墓穴和平原堡垒位置。

坐标使用游戏世界的 `X / Y / Z`。在 M 键地图上，`X` 为东西方向，`Z` 为南北方向，`Y` 是高度。“已生成”表示存档中的地点生成标记为真；“预定位置”是世界地点表里的计划位置，后续游戏版本或模组更新可能改变未生成地点。
